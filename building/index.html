Builds

An index of things I've made, in no particular order.

  1. Tablingos

    Founder and CEO. Built a SaaS platform for managing end-to-end data pipelines for normalization and integration. Funded by Microsoft.

  2. Pocket Prosthetic

    A mobile app that uses mobile LiDAR sensors to generate 3D scans of residual limbs to build molds for prosthetics. Won Hack the 6ix.

    GitHub

  3. PROPEL Lab work

    Worked under Dr. Jan Andrysek to develop an algorithm for an iOS application for accurate out-of-clinic gait rehabilitation and monitoring.

    Lab

  4. Big Data Challenge

    Conducted a study on the impact of urban heat islands on monarch butterfly population dynamics. Presented our work in front of important stakeholders, such as the Lieutenant Governor of Ontario. Won the CCUNESCO Award ($1k).

    Website

  5. CarNET

    A connected-vehicle prototype that lets cars broadcast intended actions so nearby systems can respond earlier and more safely.

    GitHub · Demo

  6. Sparklog

    Every meal tracking app I've used is either too complex or inaccurate. I made one that makes meal tracking as simple as writing logs in an apple note, and uses LLMs and search to automatically extract accurate nutrition information.

    Website

  7. TrackBack

    A conversational lost-item finder that guides seniors with dementia through retracing their steps and searching for misplaced essentials. Presented at Hack the North.

    GitHub

  8. No Rot

    Gen Z communication is riddled with brain rot. I made a Chrome extension that acts as Grammarly for brain rot by suggesting better alternatives and giving feedback.

    GitHub
